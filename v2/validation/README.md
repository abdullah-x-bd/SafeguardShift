# V2 validation artifacts

SafeguardShift V2 does not use or claim external human expert certification.

The active pre-canonical gate is the frozen Triangulated Synthetic Construct Validation regime documented in `../docs/CONSTRUCT_VALIDATION.md`.

The canonical validation summary is stored at `results/v2/construct_validation.json` after a successful run. Raw panel outputs are retained as a workflow artifact and are not used to score canonical agent trajectories.

The historical plan for human expert review is preserved only in git history and `../docs/AMENDMENTS.md`.
