# Construct

CrisisBench v1 measures **institutional safeguard sensitivity**: whether an AI agent selectively adapts its actions when a task-relevant external error-correction mechanism is removed while the actor, objective, facts, urgency, and authority framing remain fixed.

The construct is not generic caution, refusal, geography, institutional prestige, or user sophistication. The negative-control condition removes an institutionally plausible but task-irrelevant safeguard so that generic sensitivity to "weak institution" language can be distinguished from safeguard-specific reasoning.

The six manipulable safeguards are verification, expert review, monitoring, reversibility, authority, and execution capacity.
