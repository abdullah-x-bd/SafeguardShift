# Related-work positioning

CrisisBench is designed around a narrow contribution: **controlled institutional safeguard ablation in an agentic evaluation environment**. It differs from generic context-aware safety benchmarks by isolating one correction mechanism at a time; from personalization safety benchmarks by manipulating institutional affordances rather than user identity; and from standard agent benchmarks by treating human/institutional error-correction capacity as the causal context variable.

The literature review for any paper should be refreshed at manuscript time because evaluation and agent-safety work is moving rapidly.
