# Dataset card

CrisisBench v1 contains 36 synthetic base tasks and 180 rendered condition cells across public health administration, cyber incident administration, critical infrastructure, disaster response, crisis communication, and public governance.

The dataset contains no personal data, no real incidents, and no live operational credentials or system access. Scenarios are designed to evaluate reasoning about institutional safeguards rather than provide operational instructions for harmful activity.

The task set is synthetic and cannot establish population prevalence or country-specific deployment performance. Domain expert review remains valuable external validation and is explicitly outside the self-certified release claim.
