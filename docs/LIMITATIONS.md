# Limitations

CrisisBench uses synthetic tasks, a bounded action vocabulary, and explicit safeguard descriptions. Real institutional capacity is more continuous and endogenous. Tool-call competence may confound measured adaptation, so tool failure rates must be reported. The benchmark does not capture all coordination, political, legal, cultural, or resource constraints that shape real crisis response. The v1 action contracts encode a research abstraction, not universal domain doctrine. Independent domain-expert review and external reproduction are not self-certified by this repository.
